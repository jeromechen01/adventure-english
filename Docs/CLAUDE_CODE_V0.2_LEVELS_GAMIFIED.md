# ★★★ 模块 1：单词闯关系统（核心，按"做一款游戏"的标准来）

## 一、设计哲学（先理解，再动手）

小孩子愿意反复玩一个游戏，靠的不是"题目本身"，而是这些**上瘾机制**。你要把它们真正做进闯关里：

1. **即时反馈循环**——每一次操作（每答对一题）立刻有视觉+听觉+数值反馈，不要等整关结束才结算
2. **连击与爽感**——连续答对累积 combo，倍率越来越高，断了心疼，让孩子想"保住连击"
3. **风险张力**——限时/生命值制造适度紧张，"差一点就过了"激发再来一次
4. **随机惊喜**——宝箱、暴击、随机奖励，不确定性是上瘾的核心引擎
5. **可见成长**——解锁新区域、宠物进化、图鉴收集，让孩子看到"我变强了"
6. **多样性**——关卡玩法有变化，不是每关都一模一样的 4 个环节，防止腻
7. **失败也愉快**——没过关不打击，给鼓励+"就差一点"，让孩子愿意重试

## 二、闯关地图（探险旅程感）

### 划分规则
- 每关 8 个单词，关卡数 = `Math.ceil(年级词数 / 8)`
- 把年级所有 unit 的词扁平化后按 8 切分
- 第 1 关默认解锁，过关（≥1星）解锁下一关，已过关可重刷取最高星

### 地图视觉（像游戏关卡地图，不是列表）
- **SVG 贝塞尔曲线画蜿蜒小路**（`C` 命令，不要直线）串起所有关卡，已通关段暖色 #FF8A4C、未解锁段灰色
- 关卡节点是**圆形徽章**（56-64px），左右交替 zigzag 分布
- 三种状态视觉区分：已通关（彩色+头顶星星⭐×1-3）/ 当前可挑战（pulse-glow 呼吸+📍标记+宠物站在上面）/ 锁定（灰+🔒+半透明）
- **分区主题**：每 5 关为一个"大区"，不同大区不同场景主题色和装饰——如第 1-5 关"草原"🌳🌸、6-10 关"海边"🌊🐚、11-15 关"雪山"⛄❄️、16+ "太空"🚀⭐，让孩子有"探索新世界"的期待
- **里程碑关**：每 5 关的最后一关是 **Boss 关**（节点用 👑 或 🐉，更大更醒目），玩法更难、奖励更丰厚
- 顶部进度："已通关 X/Y · ⭐N星 · 当前大区：草原"
- 背景柔和渐变，沿路散布装饰 emoji（伪随机固定位置，不抖动）
- 进入地图自动滚动到当前关

## 三、单关玩法（重头戏：把答题变成游戏）

### 关卡开始：仪式感
进入关卡先有个 **0.5 秒的开场动画**：显示"第 N 关"+本关主题+"准备好了吗？"+ 倒数 3-2-1，然后开始。给孩子"一局游戏开始了"的仪式感。

### 关内通用 HUD（始终显示在顶部）
- ❤️ **生命值**：3 颗心，答错扣 1 颗，扣光本关失败（可重来）
- 🔥 **连击数 Combo**：连续答对累加，断了归零
- ⚡ **连击倍率**：combo 越高金币倍率越高（combo 1-2 倍率×1，3-5 ×2，6+ ×3），用醒目数字显示当前倍率
- ⭐ **本关已得分/星进度**
- ⏱️ 部分玩法有限时条

### 即时反馈（每答对一题都要有，这是爽感来源）
答对时**立刻**触发（不要攒到关末）：
- 金币图标从答案位置**飞向顶部金币栏**的动画
- combo 数字**弹跳放大**+1
- 答对音效（复用 playSound('correct')）
- 偶发**暴击**（10% 概率）：金币翻倍，屏幕闪金光，显示"💥 暴击 ×2！"
- 宠物在角落**做欢呼动作**（放大跳动）
- 连击里程碑特效：combo 到 5/10 时全屏短暂彩带 + "🔥5连击！太棒了！"

答错时：
- 心碎动画（❤️→💔）+ 错误音效 + 轻微屏幕抖动（shake）
- 不羞辱，显示正确答案 + 一句鼓励（"没关系，记住它就好！"）
- 这个词标记进错词强化队列

### 多样化关卡玩法（关键：不要每关都一样）

设计 **5 种关卡玩法（mini-game）**，每关随机或按规则选用 2-3 种组合，避免重复腻味：

1. **⚡ 闪电选择**（中译英/英译中）：给中文/英文，4 选 1，**有倒计时**（每题 8 秒），答得快额外加分。倒计时条在缩短，制造紧张感。

2. **🧩 字母拼拼乐**（拼写）：复用现有消消乐逻辑，给中文+乱序字母块，点击拼出单词。拼对字母块**爆炸消失**特效。

3. **👂 听音辨词**：播放单词发音，从 4 个选项选对应的词（练听力）。

4. **🎯 快速反应**（复用打地鼠思路）：屏幕快速闪现单词，限时点击正确的，连续正确触发"手感火热"状态。

5. **🐉 Boss 战**（每 5 关的里程碑关专用）：把本大区学过的词做成"Boss 血条"，每答对一题对 Boss 造成伤害，答错 Boss 反击扣心，限时内打败 Boss 过关。Boss 用大 emoji（🐉👹🦖），有受击动画。**Boss 关奖励翻倍 + 必掉卡牌。**

### 关卡内出题策略（融合错词强化）
本关 8 个词里，如果该年级有未毕业的错词，**强制混入 1-2 个错词**复现（替换部分新词），让错词反复出现加强记忆。

## 四、过关结算（即时满足 + 期待下一关）

### 结算动画序列（依次播放，有节奏感）
1. "🎉 关卡完成！"大字弹入
2. **星星逐颗点亮**（根据正确率，一颗一颗 duang 地亮起，配音效）
3. **金币数字滚动累加**（从 0 滚到本关总金币，含连击/暴击加成）
4. **最大连击展示**："最高连击 🔥12！"
5. **宝箱环节**（随机惊喜）：3 星通关或 Boss 关，出现一个**会晃动的宝箱**，点击打开，随机掉落：卡牌/额外金币/宠物食物/限定装饰。开箱动画要有期待感（晃动→裂开→光芒→掉落物）
6. **宠物成长**：显示宠物经验+N，如升级则播放进化动画
7. 解锁下一关提示："🗺️ 解锁第 N+1 关！"+ 自动滚动到地图新位置

### 星级与奖励
正确率 ≥90%→3星，≥70%→2星，≥50%→1星，<50% 不过关。
- 1星 +20币 / 2星 +40币+经验10 / 3星 +60币+经验20+宝箱 / Boss关额外翻倍+必掉卡牌 / 首通额外+30币
- 连击和暴击的金币加成实时累计到本关总金币

### 失败处理（不打击，引导重试）
没过关：温和动画（不要红叉爆炸），显示"💪 就差一点点！"+本次答对了几个+"再试一次说不定就过了！"+突出"重新挑战"按钮。**失败也给少量安慰金币**（答对的题照样给基础币），让孩子不觉得白玩。

## 五、长期激励（让孩子持续回来）

- **每日首关加成**：每天第一次通关任意关卡，金币×2，鼓励每天来
- **大区通关奖励**：通关一整个大区（5 关）给大奖励 + 解锁该区"纪念徽章"
- **单词图鉴**：把闯关学过的词做成可收集图鉴（复用卡牌系统思路），收集进度可视化，激发收集欲
- **连胜记录**：记录"连续 N 关三星"，破纪录给特殊奖励

# 模块 4：跟读背诵 + 精准打分（重算法）

reading.js 基础上加两功能，新建 `assets/js/modules/recite.js`：
- **逐句跟读**：按 `.!?` 拆句，逐句 speak 示范→recognize 跟读→similarity 打分，≥75 过
- **背诵挑战**：预备(显示全文)→挖空(20%/50%/全遮三档)→录音→打分
- speech.js 新增 `alignWords(original, spoken)`：用 **LCS 最长公共子序列**做词级对齐，返回 `{tokens:[{word,status}], completeness, accuracy, score}`。status: correct/missing/extra。normalize 要展开缩写(I'm→i am)、去标点转小写。综合分=完整度×0.7+准确度×0.3
- 结果：大字分数+等级(95+完美/80+熟练/60+基本/<60继续)+逐词高亮(对绿/漏灰/错红)+完整度准确度细分
- 奖励：95+ 给100币+背诵达人勋章+经验30，80+ 60币，60+ 30币
