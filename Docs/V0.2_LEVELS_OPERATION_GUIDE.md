# V0.2 闯关趣味强化版 · 操作指南

配套提示词：`CLAUDE_CODE_V0.2_LEVELS_GAMIFIED.md`

本次升级的核心是**把背单词闯关做成小孩真正愿意玩的游戏**。这份指南教你怎么跑、怎么验收"好不好玩"、不好玩怎么让它改。

## 二、强烈建议：分阶段跑（闯关部分单独验收）

闯关是本次核心，占 60% 工作量，也最容易做得"不好玩"。**一定要单独跑、单独验收，不要和其他模块混在一起一次跑完。**

### 推荐节奏

**第一阶段：只做闯关（提示词步骤 1-5）**

启动 `claude`，贴完整提示词，**末尾加这句**：

> 请先只完成模块 1（单词闯关系统）的全部内容，即执行步骤 1 到步骤 5。做完后停下来让我试玩验收闯关的趣味性，我确认好玩之后，再继续做模块 2/3/4。

做完后**你亲自试玩**（验收方法见第三节）。这是最关键的一步——闯关好不好玩直接决定整个 app 成败。

**第二阶段：满意后做其余模块**

闯关验收通过后，对它说：

> 闯关部分我验收通过了，请继续完成模块 2（错词强化）、模块 4（背诵打分）、模块 3（趣味记忆）和剩余步骤。

## 三、闯关趣味性验收（本次重点）

做完第一阶段后，让它起服务，你**用手机**打开试玩（手机体验才准，电脑感受不到触控乐趣）。

> 手机访问方法：电脑和手机连同一个 WiFi，电脑命令行跑 `python -m http.server 8000`，看电脑 IP（cmd 输 `ipconfig` 看 IPv4 地址，如 192.168.1.5），手机浏览器访问 `http://192.168.1.5:8000`

### 逐项体验清单（边玩边对照）

**地图层面**：
- [ ] 打开闯关地图，是不是一条弯弯曲曲的路串起关卡？（不是一列方块）
- [ ] 关卡是圆形徽章吗？当前能打的关在闪烁吗？
- [ ] 往下滚，能看到不同主题的大区吗（草原→海边→雪山）？
- [ ] 每 5 关有没有醒目的 Boss 关（龙/王冠图标）？

**进关体验**：
- [ ] 进关有没有"第 N 关，3-2-1"的开场？
- [ ] 顶部有没有生命值❤️、连击🔥、倍率⚡？
- [ ] **答对一题，金币有没有飞起来？连击数字有没有跳？有没有音效？宠物有没有欢呼？**（这条最关键，是爽感来源）
- [ ] 连续答对几题，倍率会不会升高？有没有"5连击！"的特效？
- [ ] 有没有偶尔出现"暴击 ×2"？
- [ ] 答错了，是温和鼓励还是冷冰冰打叉？

**关卡多样性**：
- [ ] 打几关下来，玩法是不是有变化？（选择题、拼字母、听音、快速反应轮换）
- [ ] Boss 关是不是和普通关不一样（有血条、要打败 Boss）？

**结算体验**：
- [ ] 过关后星星是不是一颗颗点亮的？金币是不是滚动累加的？
- [ ] 三星或 Boss 关有没有开宝箱？开箱有没有期待感？
- [ ] 没过关的话，是不是鼓励"就差一点"而不是打击？

### 终极判断标准

**玩完 2-3 关后，问自己（或让孩子玩）：还想不想再玩一关？**

- 如果"还挺想再玩的" → 达标 ✅
- 如果"就是做了几道题，没什么感觉" → 没达标，要返工

## 四、不好玩怎么让它改（返工话术）

根据具体问题，把对应的话甩给 Claude Code：

**问题：还是像答题器，没有游戏感**
> 闯关现在还是像在做题，缺乏游戏的爽快感。请重点加强即时反馈：每答对一题，立刻让金币图标从答案位置飞向顶部金币栏（CSS 动画），连击数字弹跳放大，播放音效，宠物在角落跳动欢呼。连击到 5/10 时全屏彩带特效。加入 10% 概率的暴击（金币翻倍+金光闪烁）。这些是游戏爽感的核心，必须做出来。

**问题：每关都一样，玩两关就腻**
> 关卡玩法太单一了，每关都是一样的。请实现至少 4 种不同的关卡玩法轮换：闪电选择（限时4选1）、字母拼拼乐（拼字母块）、听音辨词（听发音选词）、快速反应（限时点击闪现的词）。每关随机组合 2-3 种，让孩子不会腻。

**问题：地图不好看**
> 闯关地图还是不够像游戏。请用 SVG 贝塞尔曲线画一条平滑蜿蜒的小路连接关卡节点，节点做成圆形徽章左右交替分布，每 5 关换一个主题大区（草原🌳/海边🌊/雪山⛄）有不同装饰，每 5 关放一个 Boss 关大节点（🐉）。参考多邻国 Duolingo 的学习路径地图。

**问题：没有 Boss 关 / Boss 关没意思**
> 请把每 5 关的里程碑关做成 Boss 战：屏幕上一个大 Boss（用 🐉👹 emoji）带血条，每答对一题对 Boss 造成伤害扣血，答错 Boss 反击扣孩子的心，限时内打败 Boss 才过关，Boss 受击有抖动动画。Boss 关奖励翻倍且必掉卡牌。

**问题：过关结算太平淡**
> 过关结算太平淡。请做成有节奏的动画序列：先"关卡完成"弹入，然后星星一颗颗 duang 地点亮（带音效），金币数字从0滚动累加到总数，显示最高连击，最后 3 星或 Boss 关弹出一个会晃动的宝箱，点击开箱有"晃动→裂开→光芒→掉落物"的期待感动画。

**问题：失败让孩子有挫败感**
> 没过关时不要用红叉、爆炸这种打击性反馈。改成温和鼓励：显示"💪 就差一点点！"+本次答对了几个词+"再试一次说不定就过了"，突出"重新挑战"按钮，并且答对的题照样给金币，让孩子不觉得白玩。

**问题：手机上动画卡顿 / 节点错位**
> 闯关在手机上[卡顿/节点重叠/错位]。请优化：动画用 CSS transform 和 requestAnimationFrame，避免重排；地图节点在 375px 窄屏下间距和路径要正常不重叠；触控按钮≥44px。

## 五、其余模块验收（第二阶段做完后）

闯关满意、其余模块也做完后，快速验收：

- **错词突击**：故意答错几个词 → 看"🔥错词突击"入口数字有没有增加 → 进去连对 3 次看词会不会"毕业"
- **趣味记忆**：看单词卡的"💡趣味记忆"，质量行不行（不能有"记住就行"这种废话，谐音要和词义有关）
- **背诵挑战**：阅读选一篇 → 背诵挑战 → 完整背一遍给高分、故意漏几句看完整度下降且漏的词灰色高亮

不满意的话用上一版指南里对应的返工话术（趣味记忆质量、背诵打分准确度那两段）。
